Комплект документов для лицензирования учебного центра

Для получения лицензии на образовательную деятельность учебному центру нужен пакет локальных документов. Готовые программы ПО и ДПО закрывают ключевую часть этого пакета.

Что обычно требует лицензирующий орган

Программы по реализуемым профессиям, учебные планы, рабочие программы дисциплин, оценочные материалы, приказы и положения.

Чем помогают готовые комплекты

Программа + методическое пособие + КОМ + тесты закрывают требования к содержанию и оцениванию. Документы делаются под вашу организацию.

С чего начать

Выберите профессии из перечня № 534, закажите комплекты. Пакет из 5 — самый ходовой набор для запуска.

Частые вопросы

Программы соответствуют требованиям?

Да, комплекты строятся по перечню Приказа № 534, для ДПО — по Порядку Приказа Минобрнауки № 266.

Можно ли по безналу?

Да, выставляем счёт на ООО «КВАНТ+». После оплаты высылаем файлы и закрывающие документы.
